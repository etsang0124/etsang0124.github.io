#### 🔑 Key Engineering Highlights:
- **Unified Native & Web Build**: Compiled via React Native Web and Expo SDK 54 into a single, responsive cross-platform runtime that operates seamlessly on iOS (Expo Go) and browsers.
- **Physical Media Isolation**: Public listing photography in `/media/` auto-strips EXIF and transcodes HEIC $\to$ JPEG, while unindexed KYC files (passports, pay stubs) reside strictly under `/private/` guarded by RBAC sessions.
- **Auditable Multi-Objective Scoring**: Ranks homes based on budget tolerance decay, MTA commute matrices to renter anchor locations, and behavioral engagement priors.
