Quantitative Architecture

Recommendation Engine Pipeline

Replacing static keyword filters with a multi-objective scoring pipeline that penalizes subway transit friction and amortizes free-month concessions into true net-effective rent.

PRODUCTION SCORING FUNCTION
Score(i) = w_commute · C(i) + w_rent · R(i) + w_amenity · A(i) + w_quality · Q(i)

Normalized [0, 1] affinity score combining exponential transit decay with price elasticity, tailored to each renter's true lifestyle constraints.

01 / COMMUTE DECAY
Transit Friction Curve
Commutes under 25 minutes receive maximum affinity. Beyond 25 mins, an exponential decay penalty reflects subway dissatisfaction: C(t) = exp(-λ · max(0, t - 25)).
02 / CONCESSIONS
Net-Effective Amortization
Landlords often mask high rents with free months. SkyLoft dynamically amortizes bonuses across lease durations: Net = Gross × (1 - M_free / Term).
03 / FALLBACK
Tiered Constraint Relaxation
When strict filters yield sparse vacancy, the engine automatically relaxes secondary parameters (+5 mins transit buffer) while strictly protecting budget caps.
