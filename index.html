03. Recommendation System Engine Architecture

Traditional rental portals (StreetEasy, Zillow) rely on primitive keyword search and paid broker promotion. SkyLoft replaces static filters with a multi-objective scoring pipeline that amotizes concessions and minimizes transit commute friction.

Algorithm Specification Production Scoring Pipeline
Score(i) = w_commute · C(i) + w_rent · R(i) + w_amenity · A(i) + w_quality · Q(i)

Scores are normalized between [0, 1] through an exponential decay transit matrix and net-effective price elasticity curve, delivering mathematically tailored apartments aligned with each renter's true lifestyle constraints.

01 / TRANSIT DECAY

Commute Decay Curve

Commutes under 25 minutes receive maximum affinity. Beyond 25 minutes, exponential penalties reflect real subway dissatisfaction: C(t) = exp(-λ · max(0, t - 25)).

λ = 0.045 / min
02 / NET EFFECTIVE

Concession Amortization

NYC landlords frequently mask high rents with free-month concessions. SkyLoft dynamically amortizes bonuses across lease durations to surface true monthly cash obligations.

Net = Gross × (1 - M_free / Term)
03 / CONSTRAINTS

Tiered Relaxation

When hard filters return sparse vacancy, the engine automatically relaxes secondary parameters (e.g., commute buffer by +5 mins) while preserving core budget and room count thresholds.
